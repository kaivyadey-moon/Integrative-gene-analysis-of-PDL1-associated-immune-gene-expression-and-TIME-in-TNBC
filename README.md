# Integrative Analysis of PD-L1 Associated Immune Gene Expression and TIME in TNBC

Bachelor's dissertation project.

## Objectives
To investigate PD-L1-associated immune signatures in Triple Negative Breast Cancer using TCGA-BRCA transcriptomic data accessed via UCSCXena.

## Methods
- TCGA-BRCA data retrieval
- TNBC Basal-like filtering
- PCA and heatmap analysis
- limma-voom differential expression
- CIBERSORTx immune deconvolution
- Tumor Mutational Burden analysis
- Spearman correlation
- Kaplan-Meier survival analysis
- Tumor-Reactive Score (TRS)
